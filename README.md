# DivulgaCE

Painel de transparência dos gastos públicos do Governo do Estado do Ceará. O frontend usa React, Vite, CSS e ícones Lucide.

## Como rodar o projeto

A partir da raiz do repositório, entre na pasta do aplicativo e instale as dependências com uma versão compatível do Node.js.

```sh
cd DivulgaCE
npm ci
npm run dev
```

Abra o endereço exibido no terminal. Use `npm run lint` para verificar o código e `npm run build` para gerar a versão de produção.
